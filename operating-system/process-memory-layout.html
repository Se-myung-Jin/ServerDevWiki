먼저 읽을 것: 프로세스와 스레드

핵심 요약

프로세스의 주소 공간은 크게 코드 · 데이터 · 힙 · 스택으로 나뉜다. 코드와 데이터는 크기가 실행 전에 정해지고, 힙과 스택은 실행 중에 늘어난다.

교과서 그림에서는 힙이 위로, 스택이 아래로 서로를 향해 자란다. 실제로는 그 사이를 공유 라이브러리와 파일 매핑이 차지하고, 스택은 스레드마다 크기가 정해져 있으며, 영역의 시작 주소는 실행할 때마다 무작위로 바뀐다(ASLR).

동작 원리

영역마다 자라는 방향과 성질이 다르다

영역무엇이 들어가나크기가 정해지는 때
텍스트기계어 명령컴파일 때. 실행 중 읽기 전용이다
데이터초기값이 있는 전역·정적 변수컴파일 때. 실행 파일에 값이 들어 있다
BSS초기값이 없는(0으로 시작하는) 전역·정적 변수컴파일 때. 크기만 적어 두고 적재할 때 0으로 채운다
힙실행 중 동적으로 할당한 것실행 중. 요청할 때마다
메모리 맵 영역공유 라이브러리, 파일 매핑, 큰 할당적재할 때와 실행 중
스택지역 변수, 함수 호출 기록스레드를 만들 때 최대 크기가 정해지고, 그 안에서 호출마다 늘고 준다

데이터가 둘로 나뉘는 것은 실행 파일 크기 때문이다. 초기값이 있는 것은 값을 파일에 담아야 하지만, 0으로 시작할 것은 크기만 적어 두면 된다. 그래서 큰 배열을 초기값 없이 전역으로 두어도 실행 파일이 커지지 않는다.

텍스트는 읽기 전용이라 같은 프로그램을 두 개 실행해도 물리 페이지를 함께 쓴다. 공유 라이브러리도 마찬가지로 여러 프로세스가 나눠 쓰고, 매핑한 파일은 전체를 복사하지 않고 실제로 접근한 만큼만 읽어 들인다.

C#에서는 무엇이 어디에 있나

.NET의 관리 힙(GC 힙)은 C의 malloc 힙과 별개로, 런타임이 메모리 맵 영역에 직접 잡아 관리한다. new로 만든 객체는 여기에 있다. 스택에는 지역 변수가 놓이는데, 값 타입은 값 자체가, 참조 타입은 참조(64비트에서 8바이트)만 놓이고 객체는 GC 힙에 있다. 람다가 캡처한 지역 변수나 async 메서드의 지역 변수는 컴파일러가 힙 객체로 옮기므로 스택에 남지 않는다.

C#의 static 필드는 C의 전역 변수와 달리 데이터·BSS 영역에 있지 않다. 런타임이 타입을 처음 쓸 때 따로 잡은 영역에 두고, 참조형 static 필드가 가리키는 객체는 GC 힙에 있다. 그래서 static 컬렉션에 넣은 객체는 프로세스가 끝날 때까지 GC가 회수하지 않는다. 서버의 메모리 누수에서 흔한 모양이다.

게임 서버에서는

  • 스택 오버플로는 서버를 바로 내린다. .NET에서 StackOverflowException은 catch로 잡을 수 없고 프로세스가 즉시 끝난다. 깊은 재귀(길찾기, 트리 순회, 순환 참조가 있는 직렬화)는 반복문과 명시적 스택으로 바꾸거나 깊이에 상한을 둔다.
  • 메모리 사용량은 영역별로 본다. 덤프나 dotnet-counters로 GC 힙 크기와 프로세스 전체 메모리를 비교하면, 늘어난 것이 관리 객체인지 네이티브 라이브러리·스레드 스택인지 가를 수 있다.

주의 사항

  • 스택이 자라다가 힙을 침범하는 것이 아니다. 스택 크기는 스레드를 만들 때 정해지고, 그 끝에는 접근이 막힌 가드 페이지가 깔려 있다. 넘치면 그 페이지에 접근해 폴트가 난다. 힙과 마주 보며 서로를 침범하던 것은 예전 구조다.
  • 스택 오버플로와 힙 고갈은 다른 실패다. 스택은 넘치는 순간 그 자리에서 죽는다. 힙은 할당 함수가 실패를 알려 주는 것이 원칙이지만, Linux는 기본적으로 메모리를 실제로 쓸 때까지 내주는 것을 미루기 때문에(overcommit) 할당은 성공하고 나중에 OOM killer가 프로세스를 죽이는 일도 있다. Windows는 반대로 할당(커밋)하는 순간 쓸 수 있는 양을 따져서, 모자라면 그 자리에서 실패시킨다.
  • 주소만 보고 영역을 짐작하지 않는다. ASLR 때문에 영역의 시작 주소는 실행마다 다르다. 주소를 그 프로세스의 메모리 맵(Linux /proc/<pid>/maps, 디버거의 모듈 목록)과 비교해서 판단한다.
  • C·C++의 전역 변수는 힙에 있지 않다. 전역은 데이터·BSS 영역이고, 힙에는 실행 중에 요청해서 받은 것만 들어간다. 수명이 다르고, 해제하는 주체도 다르다. C#의 static은 위에서 본 것처럼 다르다.
